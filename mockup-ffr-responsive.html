Penyebab utama kenapa di HP jadi sempit (sudah ditemukan)

Di public/assets/css/style.css aturan #wrapper mengunci width: calc(100% - 260px). Saat FFR dipanggil, #wrapper.no-sidebar hanya me-reset margin-left tetapi tidak me-reset width. Di HP 390px hasilnya 390 − 260 = 130px (terukur 115px setelah padding) — itulah kenapa semua halaman FFR gepeng. Perbaikannya satu baris:

#wrapper.no-sidebar { margin-left: 0 !important; width: 100% !important; }
